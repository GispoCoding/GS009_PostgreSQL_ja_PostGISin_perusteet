## GS009 Introduction to PostgreSQL and PostGIS

This repo contains the necessary files and configurations for setting up the training environment for  Gispo's PostGIS courses in AWS. 

The English course is called Introduction to PostgreSQL and PostGIS and the Finnish one PostgreSQL ja PostGISin perusteet. Both courses use this repo for setting up the training environment.

This repo does not contain any exercises, they reside in the master-training-data in folders [GS009](https://github.com/GispoCoding/master-training-data/tree/main/src/GS009) and [GS009_eng](https://github.com/GispoCoding/master-training-data/tree/main/src/GS009_eng)
